# get classes vector

get classes vector

## Usage

``` r
get_classes(start_date, sessions, class_frequency = "weekly")
```

## Arguments

- start_date:

  (chr) in the format of YYYY-MM-DD

- sessions:

  (int) number of sessions

- class_frequency:

  (str) frequency of classes, Options = "weekly", "biweekly", Default =
  "weekly"
