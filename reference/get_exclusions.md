# get exclusion dates

get exclusion dates

## Usage

``` r
get_exclusions(start_date, sessions, class_frequency = "weekly")
```

## Arguments

- start_date:

  (date) start date

- sessions:

  (integer) number of sessions

- class_frequency:

  (str) frequency of classes, Options = "weekly", "biweekly", Default =
  "weekly"
