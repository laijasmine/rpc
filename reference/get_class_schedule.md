# get_class_schedule

get_class_schedule

## Usage

``` r
get_class_schedule(instructor = NULL, sheet)
```

## Arguments

- instructor:

  (chr) name of instructor

- sheet:

  (str) name of sheet to use

## Value

tibble

## Examples

``` r
if (FALSE) get_class_schedule("First Last", sheet = "2026 Winter") # \dontrun{}
```
